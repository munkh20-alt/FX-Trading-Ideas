# FX арилжааны санааны шинжилгээний самбар

Форекс, металл, индекс, криптогийн техник + макро шинжилгээгээр арилжааны санааг эрэмбэлдэг нийтийн самбар.

* GitHub Actions цаг тутам ботыг ажиллуулж, самбарыг GitHub Pages-д нийтэлнэ.
* Үнэ: Yahoo Finance (брокерын үнээс бага зэрэг зөрнө). Календарь: ForexFactory + Myfxbook.
* Лот, эрсдэлийг $100,000-ын жишээ дансаар тооцно.

**Энэ нь санхүүгийн зөвлөгөө биш.** Түүхэн тестээр (15 жил) эдгээр санаа зардлын дараа дунджаар эерэг үр дүн
өгөөгүй — зөвхөн шинжилгээ, суралцах зорилготой. Арилжааны шийдвэрийг та өөрөө гаргана.
